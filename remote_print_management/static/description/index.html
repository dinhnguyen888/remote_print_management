Comprehensive Suite

Key Feature Highlights

A centralized, intelligent print management cockpit integrated directly within your Odoo backend.

🖨

1. Direct & Silent Printing

Auto-trigger prints on record validation (e.g. Validate Invoice → auto-print invoice; Validate Picking → auto-print label).

🖥

2. Multi-Node & Multi-Printer Routing

Auto-detect printers connected via USB, LAN/IP, or Bluetooth across unlimited print stations and branches.

📝

3. Print Job Lifecycle & Queue Control

Track execution state (Pending • Printing • Done • Error). 1-click reprinting if a printer runs out of paper.

📈

4. Live Dashboard & Dropzone

Monitor printer health metrics and test printing directly with an interactive drag-and-drop PDF test dropzone.

👤

5. Role-Based Access Control (ACL)

Standard users print seamlessly, while node setup, token management, and router settings are protected.

🔍

6. Optional Preview Modal

Print completely silently with 0 clicks, or show an interactive popup to review pages and customize copies.
