Key Feature Highlights

A centralized, intelligent print management cockpit integrated directly within your Odoo backend.

1. Direct & Silent Printing

Send print jobs automatically on record validation (e.g., validate Invoice → auto-print invoice, validate Picking → auto-print packing label) directly to designated physical printers.

2. Agent Node & Multi-Printer Routing

Manage unlimited print stations across multiple locations. Auto-detect printers connected via USB, Network (IP/TCP), or Bluetooth, and map specific Odoo reports to designated printers.

3. Print Job Lifecycle & Queue Control

Track the exact execution state of every print request (Pending • Printing • Done • Error • Cancelled). Detailed error logs allow 1-click reprinting if a printer runs out of paper.

4. Live Analytics Dashboard & Dropzone

Visual health metrics displaying online vs. offline printers, success/failure charts, and an interactive drag-and-drop PDF test tool to verify physical printer output in seconds.

5. Role-Based Access Control (ACL)

Granular security access rules. Standard users can execute prints seamlessly, while node setup, printer routing, and token management are restricted to Managers & Administrators.

6. Optional Preview Dialog Before Printing

Configure whether users print silently with 0 clicks, or show an interactive Odoo popup preview to review pages, customize number of copies, or select an alternate printer.
